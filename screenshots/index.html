v1.0.2 变更标注（针对评审意见 · 2026-10-09）
  • 双向纠错：S04 纠正弹窗新增「实际情况是（更好 / 更差）」必选方向项——更好 → 该维度上调为「充足」；更差 → 下调为「缺失」并生成补齐行动。纠正可升可降、不一律加分。
  • 负向纠正反例：纠正「我不会 Excel，也没有 SQL 经验」→「数据分析与工具」由部分满足下调为缺失，匹配度 59% → 45%，行动清单替换为高优先级「完成 Excel 与 SQL 基础课程」等补齐行动。
  • 行动验证闭环：负向纠正的维度可通过完成行动逐级回升（缺失 → 部分满足 → 充足），匹配度 45% → 59% → 73%——纠正揭示真实差距，行动补齐差距。
  • 界面呈现：P04 匹配度卡新增「纠正修正：X% → Y%（↑/↓ N 个百分点）」对比条；维度表与纠正记录区分「已上调 / 已下调」标签；S05 横幅按方向区分文案。
  • 受影响画面：S04（弹窗布局）、S05（横幅文案 + 对比条）、P07（含纠正快照的对比条）三幅，均为 v1.0.1 基线画面，已逐幅标注变化内容；最新交互以可运行原型为准（README「评审演示脚本② 正向 / ⑤ 负向」可完整复现），规则与数字可用 node check.js 校验（113 项断言）。
